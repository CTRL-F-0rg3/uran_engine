Expand description

Kąt obrotu wokół osi Y dla wektora (kierunek facing).

Używamy atan2(x, z), a nie atan2(z, x): w tej konwencji kąt 0 oznacza „w stronę +Z“, więc wektor zbudowany z yaw wraca do yaw po odwróceniu. Odwrócona kolejność argumentów daje obrót o 90° i cała scena staje się bokiem.
