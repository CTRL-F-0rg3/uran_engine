AssetServer — punkt wejścia do ładowania assetów (obrazy, czcionki).

Wczytanie tego samego pliku dwa razy zwraca ten sam uchwyt (cache po ścieżce). Wszystko działa synchronicznie — to świadoma decyzja na tym etapie: gry 2D zwykle mają mało i małe assety, a synchroniczne API jest znacznie wygodniejsze w użyciu niż callbacki.
