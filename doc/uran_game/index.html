Demo silnika: mała arena z shooterem + armia piechoty na GPU.

Uruchomienie: cargo run -p uran-game Sterowanie: WASD/strzałki — ruch, mysz — celowanie, LPM — strzał, RMB — nowy punkt zgrupowania piechoty, F — uzupełnienie z rezerwy, P — pauza, R — restart, Esc — wyjście.
