Bind grupy i potoki renderowania.

Są dwa potoki:

  • sprite — instancjonowane prostokąty (jeden draw call na kombinację tekstura + tryb mieszania),
  • mesh — dowolne siatki trójkątów, transformacja per-draw w push constants.

Oba mają ten sam layout bind grupy (sampler + tekstura), więc jedna bind grupa obsługuje wszystkie potoki.
